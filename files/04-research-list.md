## ❓ 必须调研(P0 - 影响 MVP)

### 调研 1:JWT 用户认证

**为什么必须懂:**
- MVP 第 1 个功能就是"用户注册",必须用 JWT
- 后续所有 API 都要 token 验证

**调研内容:**
- bcrypt 密码加密原理 + 使用
- JWT token 生成 / 验证 / 过期处理
- Express 中间件保护需要登录的接口
- Token 存储位置(localStorage vs Cookie)

**资源:**
- npm 包:`jsonwebtoken`, `bcryptjs`
- 推荐教程:JWT 官方文档 + jwt.io 在线工具

**预估学习时间:半天 ~ 1 天**

---

### 调研 2:手机网页适配(响应式设计)

**为什么必须懂:**
- 用户主要在手机上用(晚上 8 点后躺床上)
- 网页必须在手机上好看好用

**调研内容:**
- `<meta viewport>` 标签设置
- CSS 媒体查询(`@media`)
- Flexbox 布局
- 移动端 vs PC 端断点设计
- 1rem = ? 适配方案

**资源:**
- MDN 文档:Responsive Design
- 推荐工具:Chrome DevTools 的移动端模拟

**预估学习时间:半天**

---

### 调研 3:服务器部署流程

**为什么必须懂:**
- MVP 上线必须有公网地址
- 不能只在本地跑

**调研内容:**
- 阿里云轻量应用服务器购买
- 域名注册 + 备案流程(⚠️ 备案要 7-15 天)
- Nginx 反向代理配置
- SSL 证书申请 + 配置
- PM2 守护 Node.js 进程
- Docker 在服务器上跑 PostgreSQL

**资源:**
- 阿里云官方文档
- Nginx 配置示例

**预估学习时间:1 天(操作)+ 1-2 周(等备案)**

⚠️ **重要警告:备案是 MVP 最大的隐性成本!**
建议**现在就开始申请域名 + 备案**,边等边做开发。

## 📌 必须警惕的"陷阱"

### 陷阱 1:备案陷阱 ⚠️⚠️⚠️

```
🔴 备案是 MVP 最容易翻车的地方:
- 备案前: 域名无法解析到大陆服务器
- 备案需要: 个人身份证 + 拍照 + 1-2 周等待
- 备案不过: 域名废了, 重新申请

✅ 解决方案:
1. 第一周就开始申请域名 + 提交备案
2. 备案期间继续开发, 用 IP 访问测试
3. 备案通过后切换到域名
```

### 陷阱 2:HTTPS 陷阱

```
🔴 开发阶段就配 HTTPS = 浪费时间:
- 本地证书麻烦
- 各种 mixed content 错误

✅ 解决方案:
- 开发阶段用 HTTP
- 上线前再配 SSL
```

### 陷阱 3:过早优化陷阱

```
🔴 MVP 阶段就做这些 = 浪费时间:
- Redis 缓存(0 个用户用啥缓存)
- 负载均衡(1 个服务器够了)
- 微服务架构(单体应用最快)
- 单元测试覆盖率(先跑通再说)

✅ MVP 原则: 能简单就简单, 能跑就行
```

### 陷阱 4:技术选型陷阱

```
🔴 不要在 MVP 阶段学新框架:
- React / Vue → V2 再说
- TypeScript → 看情况
- GraphQL → 不需要
- Redis → 不需要

✅ 只用你已经会的东西
✅ 学习时间应该花在【产品验证】, 不是【技术炫技】
```
