## 核心用户:阿强(虚构,但就是我自己)

### 基础信息

| 维度 | 内容 |
|---|---|
| 年龄 | 25 岁 |
| 身份 | 打工人(白天上班) |
| 每天玩游戏时长 | 3 小时左右 |
| 三角洲段位 | 黑鹰(中等偏上) |
| 主要活跃时段 | **晚上 8 点之后** |

### 阿强讨厌的事(真实痛点)

🔴 **核心痛点 1:抢包**
- 别人不合理分配物资,自己拿大头
- 队友互相抢战利品,毁了配合

🔴 **核心痛点 2:压力队友**
- 装备好就开始指挥别人怎么打
- 把队友当工具人

🔴 **核心痛点 3:骂人**
- 一打不好就开始情绪化输出
- 整局游戏体验崩溃

🔴 **核心痛点 4:不知道队友性格,不敢开麦**
- 这是产品的**根本性痛点**
- 也是其他平台都没解决的核心问题

## 阿强的真实需求

> "我想找几个性格好、玩法合拍的固定搭子,
> 每天晚上 8 点开黑,不用每次都赌人品。"

## 玩法分类(MVP 核心架构决策)

阿强用**二分法**自我分类,匹配的所有逻辑都基于这两类:

```
跑刀型 🏃
├─ 苟到决赛圈
├─ 优先跑物资
├─ 不主动开战
└─ 战术保守

猛攻型 ⚔️
├─ 主动开战刚枪
├─ 享受高风险高收益
├─ 喜欢挑战强敌
└─ 战术激进
```

**为什么用二分法不用 5 道题:**
- 三角洲玩家 80% 的自我认知就是这两类
- 二选一比 5 题简单,用户秒选
- 大幅降低匹配算法复杂度
- 后续可在子选项里细分(V1.5)

## 用户行为画像

### 一天的使用场景

```
晚上 8 点
├─ 阿强吃完饭, 打开手机
├─ 访问平台 H5 网页
├─ 看到推荐 3 个候选搭子
│   ├─ 候选 1: 性格开朗 + 跑刀型 + 信用分 4.5⭐
│   ├─ 候选 2: 沉稳 + 跑刀型 + 信用分 4.8⭐
│   └─ 候选 3: 战术派 + 猛攻型 + 信用分 4.2⭐
├─ 点开候选 1 详情, 看标签和评论
├─ 决定"想一起玩"
├─ 对方也点了"想一起玩" → 系统互换游戏 ID
├─ 在三角洲游戏内加好友
├─ 开始组队游戏
├─ 1 小时后回到平台
└─ 弹出强制评分: 给队友打 5⭐ + 选择"开朗"标签
```

### 使用频率

| 时段 | 频次 | 用途 |
|---|---|---|
| 早上 | 0 | 上班,不玩游戏 |
| 中午 | 0-1 | 偶尔刷一下"看看有没有新搭子" |
| 晚上 8 点 | 1 次 | **主战场**,匹配开黑 |
| 晚上 10 点 | 1 次 | 打完一局,回来评分 |
| 凌晨 | 0 | 该睡了 |

**结论:这是一个【晚高峰型】产品,资源调度可以倾斜到 8-12 点。**

## 用户愿意做的事 ✅

- ✅ 注册账号(邮箱/微信,30 秒内)
- ✅ 选择玩法标签(跑刀/猛攻)
- ✅ 填游戏作风测试(5 题以内)
- ✅ 给队友评分(因为关乎自己利益)
- ✅ 推荐朋友(换 VIP 匹配)
- ✅ 举报违规行为
- ✅ 接受简单的游戏 ID 绑定

## 用户不愿意做的事 ❌

- ❌ 上传太多个人信息(隐私顾虑)
- ❌ 实名认证(身份证认证)
- ❌ 看一堆广告
- ❌ 付费才能匹配
- ❌ 复杂的注册流程(>3 步)
- ❌ 视频/直播认证

## 关键机制设计

### 1. 数据自纠机制(核心护城河)

```
注册初期:
   用户自己填问卷 → 数据可能不准

游戏后期:
   队友评分覆盖自填数据 → 真实性格浮现

→ 平台越用越准
→ 这就是【数据飞轮】, 别人抄不走
```

### 2. 激励兼容设计(评分动力)

| 设计要点 | 具体做法 |
|---|---|
| 评分时机 | 打完一局, 结算页**强制弹出** |
| 评分难度 | 1 秒搞定: 点星 + 选标签(可选) |
| 不评分的代价 | 下次匹配延迟 / 降权 |
| 评分的收益 | 关乎自己以后匹配的队友质量 |

### 3. 奖惩闭环

```
┌──────────────────────────────────┐
│  好行为 → 高评分 → 高信用 → 优质池  │
│  坏行为 → 低评分 → 低信用 → 烂池子   │
│  极差行为 → 举报 → 幸运分降 → 封禁  │
└──────────────────────────────────┘
```

## 为什么用我们 vs 其他方案

| 方案 | 痛点 | 我们的优势 |
|------|------|----------|
| QQ 群 | 500 人里不知谁是好队友,不敢主动组队 | 性格数据 + 信用分,看得见的合拍度 |
| 腾讯官方匹配 | 只看实力不看人品,可能匹配到压力党 | 性格匹配 + 信用分过滤 |
| 微信好友 | 玩同游戏的人太少,时间对不上 | 庞大同好池 + 时段筛选 |
| 比心/捞月狗 | 要付费,本质是陪玩 | 完全免费,真实玩家 |

## 关键洞察(today's insights)

通过今天下午的练习,产出的 4 个产品级洞察:

🌟 **洞察 1:二分法分类**
- 把性格简化为"跑刀/猛攻"二选一
- 极大降低用户决策成本和算法复杂度

🌟 **洞察 2:数据自纠机制**
- 自填可以撒谎,队友评分会还原真相
- 长期数据越来越准

🌟 **洞察 3:激励兼容设计**
- 不评分的代价 > 评分的成本
- 用户会主动评分(因为关乎自己利益)

🌟 **洞察 4:完整奖惩闭环**
- 好行为有奖,坏行为有惩
- 平台自动净化,不需要人工管理
