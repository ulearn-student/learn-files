## 🎯 一分钟看懂这个项目

**做什么:** 三角洲行动玩家的固定队友匹配平台

**核心机制:** 性格作风测试 + 队友互评信用分 → 帮玩家避开烂队友

**MVP 范围:** 5 个核心功能(注册 / 玩法标签 / 匹配 / 详情 / 评分)

**技术栈:** Node.js + Express + PostgreSQL + 原生 HTML(全是已会技能)

**预估工时:** 20-30 小时核心开发 + 2-3 天部署调研

---

## 🌟 R0 阶段产出的 4 个神级洞察

1. **二分法分类** — 跑刀/猛攻二选一,极简但精准
2. **数据自纠机制** — 自填数据 + 队友评分覆盖,越用越真
3. **激励兼容设计** — 不评分的代价 > 评分成本,用户主动评分
4. **完整奖惩闭环** — 好行为奖励,坏行为惩罚,平台自净化

---

## ⚠️ 6 条永不破例的"不做"

1. ❌ 不做陪玩业务
2. ❌ 不做变声器/伪装类功能
3. ❌ 不做付费会员墙
4. ❌ MVP 阶段不做多游戏
5. ❌ 不做实名认证
6. ❌ 不做擦边/陪聊/约会功能
